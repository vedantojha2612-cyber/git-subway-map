## 🎨 Visual Identity & Kinetic Typography Rules

1. **Typography Styling**:
   - Primary Font: **Inter Black / Montserrat 900 / Anton** (all-caps, ultra-bold).
   - Accents: Monospaced code font (**JetBrains Mono / Fira Code**) for commands and commit hashes.
   - Text Colors:
     - Pure White (`#FFFFFF`) with deep black stroke/shadow (`#000000`).
     - Terminal Green (`#00FF66`) and Tokyo Yellow (`#FFCC00`) for callouts and emphasis words.
     - Brand Colors matching map lines: Tokyo Green (`#22C55E`), Ginza Orange (`#F97316`), Marunouchi Red (`#EF4444`).
   - Animation Style: Dynamic word-by-word spring scale (`pop-in`), 0.08s stagger per word, motion blur enabled.

2. **Zero AI Slop Guarantee**:
   - **No synthetic AI text-to-speech voiceover** (elevenlabs generic dev voiceover is strictly banned).
   - The video is 100% carried by authentic developer screen recording, tactile mechanical sound effects, Japanese subway transit chimes, and high-energy music cues.
   - Pure focus on real UI interactions, real code, and actual software performance.

3. **Aspect Ratio & Framing (9:16 - 1080x1920)**:
   - Central safe zone: 1080 x 1400 (avoids YouTube Shorts overlay: title, channel icon, sound pill, like/comment buttons).
   - UI elements (terminal & browser) scaled to 125%–140% so text and station nodes are crisp and legible on mobile screens without squinting.
